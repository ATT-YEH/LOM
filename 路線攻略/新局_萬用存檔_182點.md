# 新局萬用存檔（182 點）：開局配點＋第一年逐月流程
（2026-11-28 規劃；★＝攻略說法未實測；💾＝建議另存新格、永不覆蓋）

## 目的
取代傳奇019 當新的萬用存檔。019 的三個問題這局一次修好：
| 019 的問題 | 這局怎麼修 |
|---|---|
| 開局李富貴 3、丐幫 3 → 頭像沒亮也會提西武林 → 遣散、滅門全滅 | **丐幫 0、李富貴 0** → 決策走哪條由戰術決定 |
| 葉家沒入住 → 葉雲裳線、15、38 斷 | 三師兄 3 點，第一年 8 月起刷葉家入住 |
| 福韞沒認識 → 外堡刷不到龍湘 | 福韞 3 點、第一年認識；龍湘 6 點 |

**目標**：第二年 1 月下存「萬用存檔」，之後分岔拿剩下的結局（見最下面「分岔輪次」）。
